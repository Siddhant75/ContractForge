ContractForge

The Universal API & Agent Schema Studio — A zero-backend reactive tool that transforms raw API payloads into TypeScript, Zod, and AI Agent Function-Calling contracts with an in-browser Chaos Mock Runner.

🚀 The Unique Kernel

Bridges modern Web APIs and AI Agent Tool-Calling in a single reactive developer studio. Its standout differentiator is the Interactive In-Browser Mock & Chaos Runner, which automatically generates both valid payloads and boundary edge cases (nulls, missing keys, unicode strings, out-of-range integers) and validates them live against the generated Zod contract directly in the browser with zero server latency.
