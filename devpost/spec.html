⚙️ Decoupled Modular Architecture

1. Ingestion Engine

src/engine/curlLexer.ts & jsonParser.ts

  • Tokenizes shell commands into Method, URL, Query & Body
  • Sanitizes trailing commas & unquoted keys
  • Handles cURL GET requests via query params

2. AST & Semantic Inferrer

src/engine/schemaInferrer.ts

  • Recursive type inference (objects, arrays, unions)
  • Regex heuristics: ISO dates, UUIDs, emails, URLs
  • Safety depth limit guard (20 levels max)

3. Multi-Target Generators

src/engine/generators/*

  • TypeScript interfaces with optionality
  • Zod runtime validation schemas
  • OpenAI Strict tool specs (recursive additionalProperties: false)
  • Anthropic Claude tool definitions

4. Chaos Fuzzer & Runner

src/engine/chaosFuzzer.ts

  • Synthesizes valid happy-path payload
  • Fuzzes missing fields, type corruptions & boundary errors
  • Evaluates against live Zod schema in-memory
  • Zero network overhead, zero external dependencies
