The Universal API & Agent Schema Studio — Technical Blueprint & Code Tour

1. Overview & Purpose

ContractForge is a zero-latency, 100% client-side studio built for the Devpost Build With AI: Basics Hackathon. It bridges modern Web APIs and LLM Autonomous Agents by instantaneously transforming raw JSON payloads or multi-line cURL commands into strictly validated TypeScript types, Zod schemas, OpenAI Strict Structured Outputs, and Anthropic Claude Tool Calling definitions.

Its defining unique kernel is the In-Browser Chaos Mock Runner: without any backend server or external network calls, it compiles Zod schemas live in memory, synthesizes valid happy-path and deterministic edge-case mutations, and evaluates payloads in real time with simulated HTTP status diagnostics.

3. Code Tour — 3 Core Anchors

Stop 1: Resilient Input Ingestion & Tokenizer

src/engine/curlLexer.ts & src/engine/jsonParser.ts

Tokenizes bash/cmd cURL commands, normalizes line continuations (\, ^, ``` ` ```), extracts method/headers/query/body, and automatically converts query parameters into the root schema when no body is present. If JSON has syntax issues (trailing commas, comments), parseJsonResilient auto-sanitizes and surfaces a 1-click editor fix.

Stop 2: AST Construction & Semantic Inferrer

src/engine/schemaInferrer.ts

Recursively builds the normalized AstNode tree. Inspects strings against ISO-8601 timestamps, UUIDv4, email, and URL regex heuristics. Resolves object array key unions to accurately detect optional fields without losing property relationships.

Stop 3: In-Memory Schema Compilation & Chaos Mock Sandbox

src/engine/chaosFuzzer.ts & src/components/ChaosRunnerDrawer.tsx

Constructs executable Zod schemas directly from the AST. Generates deterministic mutations (missing required field, type corruption, out-of-boundary values) and verifies them via .safeParse() without eval(), displaying simulated HTTP status codes (200 OK vs 422 REJECTED) and exact field diagnostic error paths.

4. To Change This, Start Here

Add a New Sample Preset

Open src/presets/samples.ts and append an entry to the PRESETS array with an ID, title, and raw data.

Add a Semantic Type Pattern

Open src/engine/schemaInferrer.ts and add a regex pattern to detectSemanticFormat (e.g. IP addresses, phone numbers).

Add an AI Target Generator

Create a generator in src/engine/generators/ (e.g. Gemini Function Calling or MCP Tool) and add a tab in ContractStudio.tsx.

Customize Chaos Mutations

Open src/engine/chaosFuzzer.ts inside generateFuzzTestCases to introduce additional fuzz vectors (e.g. SQL injection simulation, regex boundary testing).

5. A Practice to Reuse

Decoupled AST Canonical Representation

Instead of translating directly from raw JSON/cURL syntax into TypeScript, ContractForge parses inputs once into an immutable Abstract Syntax Tree (AstNode). All downstream targets (TypeScript, Zod, OpenAI Strict Mode, Anthropic Tools, and the Chaos Fuzzer) consume the identical AST.

Why this matters on future projects: Adding new output targets or validation engines requires zero modification to input parsing logic. It eliminates combinatorial complexity (\(N \times M\) parsers/generators reduced to \(N + M\)) and guarantees consistency across all generated contracts.
